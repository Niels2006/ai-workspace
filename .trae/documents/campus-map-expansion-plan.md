# 校园大乱斗：九倍地图改造计划

## Context

当前 [multiplayer-arena.html](file:///E:/Niels/ai-workspace/showroom/schoolwork/game/multiplayer-arena.html) 是一张 `800×600` 的宿舍地图，家具同时承担绘制与碰撞，整个地图始终缩放到屏幕内。用户希望将场景改为综合校园，并把地图面积扩大约 9 倍。已确认采用“教学楼＋图书馆＋操场＋篮球场＋绿化道路”的布局，以及“跟随镜头＋小地图”的导航方式；角色、速度和射击手感保持原有尺度。

仅修改上述 HTML 文件，不新增资源文件或第三方依赖。

## 实施方案

### 1. 扩大世界并加入跟随镜头
- 将 `WORLD_W / WORLD_H` 从 `800×600` 调整为 `2400×1800`，面积正好扩大 9 倍；新增固定逻辑视口 `VIEW_W=800`、`VIEW_H=600` 与 `camera`。
- 调整 `resize()`，按视口而不是整张地图计算 `scaleX / scaleY`，避免角色缩小到三分之一。
- 新增 `updateCamera()`，让镜头跟随本地玩家并钳制在世界边界内；在开局、复活和每次本地移动后更新。
- 在 `render()` 的世界绘制阶段应用镜头平移；`screenToWorld()` 同步加回镜头偏移，保证鼠标和触摸瞄准准确。
- 复活遮罩与倒计时改为覆盖当前视口，不再使用整张世界作为覆盖范围。

### 2. 重建综合校园地图
- 用 `2400×1800` 校园布局替换现有宿舍 `OBSTACLES / OBSTACLE_LABELS`：障碍物保留 `[x,y,w,h]` 结构，并增加类型字段供分类绘制，继续复用 `circleRectCollide()` 和 `collidesWithObstacle()`。
- 设置贯通的约 160 宽十字主路，连接地图四边与各功能区；道路只绘制、不参与碰撞。
- 西北、东北布置教学楼，西侧中部布置图书馆，东侧中部布置体育馆，均为可碰撞建筑；楼间留出明显宽于角色直径的通道。
- 西南布置带跑道和足球场标线的操场，东南布置篮球场；运动场地及标线均为非碰撞地面。
- 在外围和道路两侧布置花坛、树木与林荫绿化；只有花坛和树干进入碰撞表，树冠、灌木等装饰不妨碍通行。
- 将 8 个出生点移到主路及开阔区域，确保均不与障碍重叠，并保持到各区域的多条通路。

### 3. 绘制校园并控制渲染开销
- 新增校园地面绘制函数：草地底色、道路、区域名称、跑道、足球场和篮球场标线，替换原宿舍地板与墙体视觉。
- 重写 `drawObstacles()`，按类型绘制教学楼、图书馆、体育馆、花坛和树木，不再使用床、桌、椅标签。
- 新增视野范围判断，仅绘制镜头附近的地面标线、障碍、玩家、子弹和粒子；移动、碰撞和联机状态更新仍覆盖完整世界，避免改变游戏规则。
- 不在首版引入整张地图的离屏缓存，避免高 DPR 下的大画布内存开销；以视野裁剪控制绘制量。

### 4. 增加小地图
- 在主场景恢复坐标变换后绘制小地图，放在左上角 HUD 下方，避开底部移动与射击触控区。
- 小地图按比例显示校园道路、主要建筑、当前镜头范围、本地玩家和其他存活玩家；不绘制子弹与粒子。
- 小地图只读取现有本地状态，不增加网络消息，也不拦截鼠标或触摸输入。

### 5. 更新联机隔离与界面文案
- 将 `joinDorm()` 更名为 `joinCampus()`，频道从 `dorm_brawl_v1` 升级为 `campus_brawl_v2`，防止旧宿舍客户端与新校园客户端在同一频道使用不同碰撞地图。
- 保持现有广播负载与命中、击杀、复活协议不变；各地图仍由同版本客户端静态共享，无需广播地图数据。
- 更新页面标题、主标题、英文副标题、进入按钮、玩法说明及加入/离开提示中的“宿舍”文案为“校园”；保留 analytics 的 `multiplayer-arena` 标识。

## 验证

1. 用本地 HTTP 服务打开修改后的页面，确认无 JavaScript 报错，标题与进入流程正常。
2. 进入校园后检查角色尺寸、移动速度、鼠标瞄准与射击方向；遍历地图边缘，确认镜头不错位、不露出界外。
3. 检查全部出生点、十字主路、楼间通道、建筑和绿化碰撞，确认角色不会出生卡墙，子弹能被建筑、花坛和树干阻挡。
4. 检查操场、球场、道路和区域标签的视觉辨识，小地图位置、玩家点及镜头框与实际移动一致。
5. 使用两个浏览器页面加入 `campus_brawl_v2`，验证双方可见、移动同步、射击命中、击杀计分和复活；确认不会与旧 `dorm_brawl_v1` 房间混用。
6. 调整浏览器窗口并检查高 DPR 显示与触摸坐标换算，确认小地图不遮挡 HUD 或触控按钮，移动与射击保持流畅。
